# Завдання

`python -m py_compile fixture/convert_job.py` завершується помилкою, хоча
функція і `if __name__ == "__main__"` виглядають завершеними.

Знайдіть перший невалідний рядок, поясніть походження стороннього блока,
запропонуйте мінімальне виправлення та репозиторний gate, який не дозволить
повторити інцидент. Наведіть точні `fixture/convert_job.py:рядок`.
