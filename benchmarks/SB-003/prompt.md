# Завдання

Команда `git config --get core.hooksPath` у реальному репозиторії повернула
`.githooks`. Розробник упевнений, що додав `python -m py_compile` у
pre-commit, але синтаксично зламаний `.py` усе одно було закомічено.

Дослідіть `fixture/` і назвіть точну конфігураційну розбіжність. Запропонуйте
мінімальне виправлення, яке збереже чинну генерацію changelog, та негативний
тест guard-а. Посилайтеся на конкретні файли й рядки.
