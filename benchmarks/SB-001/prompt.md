# Завдання

У `fixture/repro.py` консюмер обробляє вісім елементів. Для кожного видно
`Обробляємо: item_N`, але для частини елементів немає ані фінального успіху,
ані warning/error. Після проходу процес штатно завершується або очікує нову
роботу — deadlock немає.

Прочитайте fixture повністю й поясніть точний механізм. Відповідь має:

1. назвати гілку, яка спрацьовує для “мовчазних” елементів;
2. пояснити, чому відповідний лог невидимий;
3. спростувати версію про пропущений `await`;
4. навести щонайменше дві цитати `fixture/repro.py:рядок`.
